## Investment Thesis

Kokusai Electric builds batch atomic-layer deposition and thermal-processing tools, with a strong position in memory customers where high-throughput batch processing lowers cost per wafer. It was separated from Hitachi and listed independently, and its order book tracks memory capex closely. It competes with larger deposition vendors in single-wafer tools.

## Technology Exposure

- Batch ALD and thermal processing
- Deposition for memory and logic
- Service and retrofit

## What To Watch

- Memory capex
- Batch-versus-single-wafer adoption
- Customer concentration

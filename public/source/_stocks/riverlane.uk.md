Riverlane develops quantum error-correction decoders and control software, sold as Deltaflow, that sit between quantum hardware and applications.

Error correction is the difference between a noisy research machine and a useful computer, and it is a software and real-time systems problem as much as a physics one.

**Why it matters**

- Real-time error-correction decoders

- Hardware-agnostic software stack

- Works with multiple qubit modalities

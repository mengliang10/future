Covariant builds the software brain for robotic picking arms, trained on images and grasp attempts rather than hard-coded object models. Its RFM-1 model adds language and video inputs so operators can describe a task.

The company's systems are deployed in logistics and e-commerce operations, where the value comes from handling the long tail of unfamiliar packages without stopping the line.

**Why it matters**

- Vision-based grasping for unseen objects

- Robot foundation model with language input

- Integration with major arm and gripper vendors

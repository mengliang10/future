## Investment Thesis

Simmtech supplies package substrates for memory devices, including the small high-layer boards that sit under DRAM and NAND packages. It has been developing substrates for high-bandwidth memory and for AI-server modules, where signal integrity and layer count rise sharply. Its fortunes track Korean memory capex more closely than the wider semiconductor cycle.

## Technology Exposure

- Memory package substrates
- Module and system boards
- Substrates for HBM and advanced memory packages

## What To Watch

- HBM substrate qualification
- Korean memory capex
- Pricing pressure from substrate competitors

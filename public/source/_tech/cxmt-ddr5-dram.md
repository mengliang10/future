## What This Is

ChangXin Memory Technologies became China's leading DRAM maker on DDR4 and LPDDR4, and has been sampling DDR5 while working toward high-bandwidth memory for AI accelerators. HBM requires advanced packaging and stacking yields that few firms have mastered, and export controls limit access to some tools. Domestic DRAM matters because memory is the second-largest cost in an AI system after the accelerator.

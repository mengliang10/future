## What This Is

SMIC's N+2 process produces 7nm-class logic using deep-ultraviolet immersion lithography with multiple patterning, the route behind Huawei's domestically made advanced chips. Without extreme-ultraviolet tools, each layer needs several exposures, which raises cost, lowers yield and limits volume. It is a strategic capability rather than a commercially competitive node.

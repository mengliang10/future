## What This Is

HBM4 widens the memory interface to 2,048 bits and stacks more DRAM dies, which raises bandwidth per accelerator and shifts packaging difficulty onto the memory maker. SK hynix, the incumbent HBM leader, has targeted mass production around 2026, with custom base dies that let accelerator designers tune the memory to their chip. Supply is constrained by stacking yield and by advanced packaging capacity.

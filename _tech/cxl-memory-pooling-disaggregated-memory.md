## What This Is

CXL Memory Pooling (Disaggregated Memory).

Fundamental research phase — concept established, practical implementation remains unsolved. Our research database tracks **1 independent source** on this technology.

> CXL 2.0 switches and memory expanders shipping from Samsung (512GB CXL Memory Module), Micron, and Astera Labs (Leo CXL switch). AMD Genoa and Intel Xeon 6 support CXL 2.0 Type 3 memory pooling. Early production hardware available but software ecosystem (kernel drivers, orchestrators) still immature — few production deployments outside hyperscaler labs.
